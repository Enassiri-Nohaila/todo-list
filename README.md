📝 Simple To-Do List

📌 Description

Simple To-Do List est une petite application web qui permet de gérer facilement les tâches quotidiennes.

L'utilisateur peut ajouter une tâche, la marquer comme terminée ou la supprimer.

✨ Fonctionnalités

- Ajouter une nouvelle tâche.
- Afficher la liste des tâches.
- Marquer une tâche comme terminée en cliquant dessus.
- Supprimer une tâche.
- Empêcher l'ajout de tâches vides.

🛠️ Technologies utilisées

- HTML5 : structure de la page.
- CSS3 : mise en forme et design.
- JavaScript : gestion des tâches et interactions avec l'utilisateur.

🚀 Utilisation

1. Ouvrir le fichier "index.html" dans un navigateur.
2. Saisir une tâche dans le champ de texte.
3. Cliquer sur le bouton Ajouter.
4. Cliquer sur une tâche pour la marquer comme terminée.
5. Cliquer sur Supprimer pour enlever une tâche.
